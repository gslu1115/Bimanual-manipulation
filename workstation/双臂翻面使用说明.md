# 固定倒置单盒双臂翻面

当前任务分工按用户确认的方案：正面朝上由单臂直接归位；侧放后续由单臂拨正或转正；正面朝下作为双臂翻面与交接场景。这里的“正面”指盒体局部 +Z 胶带所在面。前向仍按无箭头胶带的 180° 对称轴评价。

本模式只处理一个固定位置、无周围障碍的倒置纸盒。控制读取仿真真值，通过 Lula IK、关节驱动和真实夹爪接触执行，不使用物体绑定或运行中位姿改写。它不是多盒任务执行器，也不是通用避碰规划器。

## 运行

双击本目录 `启动双臂翻面.cmd`，或从 PowerShell 运行：

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\asus\Desktop\sim\workstation\launch.ps1" -DualHandover
```

无窗口运行，并录制两路相机拼接的真实仿真视频：

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\asus\Desktop\sim\workstation\launch.ps1" -DualHandover -Headless -RecordVideo
```

调试动作可使用 `-NoSensors` 降低渲染记录开销，但不能与 `-RecordVideo` 同时使用。原有 `-SinglePickPlace`、`-ConveyorTest` 和默认九盒沉降入口继续保留，任务模式互斥。

## 动作与验收

1. 左臂在纸盒长轴一侧偏置夹持，抬升后搬至共同工作区。
2. 左臂把纸盒转成交接姿态，右臂从相对方向接近长轴另一侧。
3. 右臂闭合，检查夹指实际位置；左臂张开并撤离。
4. 右臂独立抬升约 4 cm 并保持，检查盒子实际跟随、左臂已经远离、无显著相对滑移。
5. 左臂回位，右臂将正面转向上方，搬运至右侧目标格，放置、张爪、撤离、回位。
6. 检查正面朝上、胶带轴朝向、位置误差、低速稳定时间、双臂回位和两只夹爪都已松开。

每段笛卡尔运动在执行前预求解 IK；不连续路径被拒绝，高关节速度段自动延长执行时间。持盒阶段监测盒子相对持有臂的平移和姿态偏差。失败时停止任务并暂停时间线；当前没有自动重试恢复策略。

## 参数与证据

参数位于 `config.json` 的 `dual_handover`，包括起点、交接中心、夹持偏置、执行速度、滑脱阈值与目标格。修改这些参数后必须重新做物理测试。

每次启动建立独立的 `outputs/dual_handover_seed_...` 目录：

- `task_report.json`：任务成功与否、失败阶段、实测交接证据和最终误差。
- `control_trace.jsonl`：双臂关节、目标、TCP、物体状态与持有臂。
- `run_status.json`、`failure.txt`：应用运行状态与异常。
- `config_used.json`：实际参数；`release_states.json`：倒置初态。
- 阶段 RGB-D、实例标签及 USD 快照：启用传感器时保存图像。
- `handover.mp4`：显式启用录像时输出；失败试验也可能产生部分录像，不能凭文件存在判定成功。

实测通过范围和最新限制以 `VALIDATION.md` 为准。
